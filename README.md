Auto Vehicle Insurance BI Project

📊 Overview

This project showcases an end-to-end Power BI solution designed for Auto Vehicle Insurance analytics. It delivers actionable insights into claims, fraud detection, and policy performance, helping stakeholders make data-driven decisions.

🚀 Key Features

Built dashboards for claims analysis, fraud detection, and policy insights.

Designed age-wise and occupation-wise claims segmentation with drill-down capabilities.

Created tooltip-based micro dashboards for detailed KPI analysis.

Identified and resolved major data discrepancies, improving overall data quality and earning leadership recognition.

🛠️ Tech Stack

Power BI Desktop & Service

SQL Server

SharePoint

Flat-file sources

DAX & Power Query

📈 Business Impact

Enhanced visibility into claims and fraud patterns.

Reduced manual reporting effort through automation.

Improved data accuracy and compliance.

Recognized by leadership for strengthening reporting quality.

📂 How to Use

Clone or download the repository.

Open .pbix files in Power BI Desktop.

Connect to sample data sources (SQL/SharePoint/flat files).

Explore dashboards with drill-down and tooltip features.
